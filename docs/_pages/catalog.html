Skill Catalogue

Every skill in this repo, grouped by whether it ships to GitHub Packages (Published) or stays inside the repo as a tool for working on the repo itself (Meta). Both are validated against the same SKILL.md spec.

The catalogue is intentionally short. Skills live here only when they are BC Gov–specific. Before adding a new skill, contributors check the upstream catalogues first. See Contribute a Skill.

Published skills

Published skills live on GitHub Packages under the @bcgov npm scope. Browse the packages page for the live list, every released version, install counts, and each package's README. See Consume a Skill for the install workflow.

Meta-skills

Skills the repo uses on itself: scaffolding a new skill, validating the spec, releasing a version. They live under .github/skills/ and are validated by the same PR check, but they are not published to GitHub Packages; they're picked up by agents working in a checkout of this repo.

Each meta-skill is a self-contained SKILL.md with its own Use When, Workflow, and Rules. Open one in the repo to see exactly when it fires and what it does.
