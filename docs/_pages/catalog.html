Skill Catalog

Every skill in this repo, grouped by whether it ships to GitHub Packages (Published) or stays inside the repo as a tool for working on the repo itself (Meta). Both are validated against the same SKILL.md spec.

The catalog is intentionally short. Skills live here only when they are BC Gov–specific. Before adding a new skill, contributors check the upstream catalogues first. See Contribute a Skill.

Published skills

Published skills live on GitHub Packages under the @bcgov npm scope. The packages page is the source of truth — it always shows the current list, every released version, install counts, and the README for each package. See Consume a Skill for the install workflow.

Meta-skills

Skills the repo uses on itself. They live under .github/skills/ and are validated by the same PR check, but they are not published to GitHub Packages — they are picked up by agents working in a checkout of this repo.
