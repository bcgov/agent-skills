BC Gov Agent Skills

A shared catalogue of agent skill profiles for the BC Government — versioned, validated in CI, and published to GitHub Packages so any team can install the same skill into any compatible agent.

Each skill is a SKILL.md manifest plus a package.json, bundled with any helper scripts, references, or assets it needs. Every change goes through a pull request, runs through the validator, and ships as a semver-tagged npm package under @bcgov/skill-<name>.

What is a "skill"? A small, focused Markdown document that teaches an AI coding agent when to act, what to do, and what to avoid. The format is interoperable with GitHub Copilot, Claude, and other agents that load SKILL.md manifests — see agentskills.io and our spec.

Meta-skills

Skills that operate on this repo itself. Validated against the same spec but not published — they ship with the repository so agents working in this checkout can use them.

  • skill-author — scaffolds a new skill profile.
  • skill-validator — explains validator failures.
  • skill-release — bumps a skill's version for release.

Why BC Gov runs its own catalogue

The most useful agent skills are specific — they encode a concrete policy, an internal service, or a known-good workflow. Generic catalogues already cover the generic ground (see the upstream catalogues we check before adding anything here). This repo only ships skills that are BC Gov–specific: skills that capture our Public Cloud Landing Zone rules, our policies, our subscription topology, and the workflows our teams have already paid the cost of figuring out.

Reuse beats rediscovery

Once a team has worked out the right way to do something inside BC Gov constraints, that knowledge belongs in a skill — not in a Confluence page or a Slack thread. The next team gets a working answer instead of a fresh investigation.

Versioned, not viral

Every skill ships as a semver-tagged npm package. Consumers pin a version; updates land deliberately. There is no shared "latest" that silently changes agent behaviour for everyone at once.
